# NewsFeed

A personalized news feed.

Everyday, the application will collect news articles, rank them according to
my interests. I can go and ask for news articles, and it will pop them off the
stack. News that are three days old or more get removed (a check is done every
hour).

For interactivity, maybe discord bot. Could think of AI integration later.
